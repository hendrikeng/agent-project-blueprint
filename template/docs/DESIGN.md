Use the existing design system and nearest live UI pattern.
Preserve semantic controls, keyboard access, visible focus, readable contrast, and applicable loading, empty, error, and denied states.
Match density and layout to actual users. Dashboard preferences are not universal product requirements.
Reusable interaction rules live in `docs/design-docs/UI-STANDARDS.md`. Concrete workflow contracts live in docs/ui/.
