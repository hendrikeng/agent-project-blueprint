Record only product-specific interaction behavior that must survive component or route changes.
Generic create, edit, delete, filter, and navigate vocabulary needs no separate registry unless code consumes it.
For each retained intent, link its owning component or API contract and define observable states.
Use the product's terminology. Keep denied, destructive, retry, and success behavior truthful.
